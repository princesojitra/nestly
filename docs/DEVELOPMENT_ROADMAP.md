# Development Roadmap

1. **Environment and project setup** — repo, docs, Git remote. *(this commit)*
2. **Product and design exploration** — two visual directions with real previews, design system, screen specs, architecture/roadmap proposal. Gate: user approval before full implementation.
3. **Foundation** — React Native CLI init, TypeScript config, design system implementation, navigation, state management, DB/backend adapters, test/lint setup.
4. **Core features**, incrementally: authentication → dashboard → inventory → asset details → warranty → maintenance → analytics → profile/settings.
5. **Offline and cloud sync** — local persistence, sync queue, retry logic, conflict handling, Supabase integration.
6. **Quality and release prep** — full test pass, iOS/Android verification, visual/accessibility/security/performance review, CI/CD, docs complete.
